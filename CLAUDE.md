# svipall

Local-first web scraping + captcha MCP server in Rust. Defeat anti-bot walls **by evading them**,
never by breaking access controls. Everything runs on this machine.

## Layout
`crates/svipall-*` plus `bench/`, a workspace member **not** under `crates/`.
- `core` — classify, ladder, identity+`coherence`, extraction, `quality`, policy, `exits`, throttle,
  widgets, `answer`, `session`, SQLite stores, config.
- `cdp` (CDP) and `quic` (quiche+h3) are **vendored**: every deviation needs a `PATCHES.md` entry.
- `http` — http tier; `impersonate` (default) = Chrome/Firefox TLS+HTTP2 on BoringSSL. `http3`
  (opt-in) uses QUIC only where `Alt-Svc` said so: never a first visit, never past a proxy.
- `solver` store+API, `dashboard` human panel, `models` ONNX, `mcp` the product (both binaries).

## How it works
- One identity (`IdentityProfile`) drives TLS, headers, CDP, the stealth script and every worker
  realm. Never state a version elsewhere. `bench fingerprint --engine chrome` checks them offline
  and fails the build.
- One DOM parse per response: ask via `ParseWants`, read from `PageParts`.
- **Nothing is ever withheld.** `quality` labels a page, never filters one (`anti_discard.rs`).
- Schema selectors are fingerprinted per domain; a redesign relocates by similarity (`healed`).
- Pointer, keyboard, wheel go through `behavior`. Never a bare click, `scrollBy` or a forged event.
- Nothing of ours may be readable from the page: no named global, no shadowed host object, no realm
  disagreeing with another. `bench tells` asserts it at every tier, offline, in `qc`.
- Hidden text never reaches the model (`extraction::sanitize`). Secrets are named from
  `~/.svipall/secrets.env`; the value never enters a call.
- Exits are the operator's; a pool keeps one (`sticky`) until retired, then heals.
  `throttle`/`exit_health`/`reputation` key by `(domain, exit)`, home address included; browser
  proxy auth is CDP, not the arg vector.
- CLI, MCP and `serve` (REST, keyed, loopback) are one server; tests keep `skill/SKILL.md` and
  `rest::ROUTES` in step with it.
- A challenge is a *modality* x a *widget*: a new one is a row in `WIDGETS` plus a fixture in
  `core/fixtures/widgets/`. `Modality::Text` is unreachable from the live loop, by test.
- `solve_loop` orders strategies by what worked on this route (`outcomes`); a decline costs no
  attempt. Never a cascade of `if`s. Then the dashboard: parked page, answer replayed.
- Answers are `core::answer::Answer`, checked against the modality. **Every coordinate is a fraction
  0..1 of its asset, never a pixel.**
- Bump `SCHEMA_VERSION` (`solver/src/db.rs`) on any schema change: every statement is
  `IF NOT EXISTS`, so without it dev works and every older machine fails.

## Rules
- **TDD.** A test before the behaviour, and it must fail without the change.
- **Quality gate** `scripts/qc.ps1` / `qc.sh` (`-Fix`/`--fix` = fmt+clippy). Integration tests
  live in `<crate>/tests/`; `#[ignore]` ones (network/browser) are run by hand.
- **Benchmarks are measured, not asserted.** Baselines in `bench/baseline/`, regenerated by its
  README: median of three runs with its range, fresh order, cooldowns cleared (never the spend), one
  residential address, no proxy. **A change counts only when the median leaves the previous
  range.** Publish the runs that improved nothing.
- **No third-party services, no remote deploy.** No API keys, no paid solvers, no geolocation.
  No vendor brand names in code; name protocols by endpoint.
- **English only.** **This file is size-guarded**; trim, don't expand.

## Build / run
`cargo build --release` (cmake, nasm, perl, llvm). Windows needs a short `CARGO_TARGET_DIR`.
`svipall-mcp` over stdio + dashboard on 8787; `svipall` is the CLI. Config `~/.svipall/config.toml`.
Env: `SVIPALL_HOME`, `SVIPALL_BROWSER`, `SVIPALL_HTTP_ENGINE`, `SVIPALL_DASHBOARD_PORT`,
`SVIPALL_REST_PORT`, `SVIPALL_API_KEY`, `SVIPALL_HUMAN_ASSIST`, `SVIPALL_HUMAN_WAIT_SECS`.
